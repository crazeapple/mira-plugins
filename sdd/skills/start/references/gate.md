# gate.md — 提交门禁程序

**无论何时、谁发起的提交，都先执行本检查。会话内首次提交前完整过一遍；此后按规则写作、提交前跑机械检查命令。** bootstrap 横切规则的指针目标。检查对象：本次提交涉及的文件。

## 机械检查（先跑）

`npx -y markdownlint-cli --disable MD013 MD024 MD056 MD060 -- <本次提交的 .md 文件>`

非零退出即阻断：按输出就地修复后重跑（禁用四项的理由：MD013 行长、MD060 表格管线对齐对中文不适用；MD024 重复标题——条目槽位跨条目同名是模板固有形状；MD056 表格列数——治理表格单元格常含竖线与复杂内容，误报频发）。此步覆盖尾随空白、连续空行、代码块语言标注、标题跳级、列表标记一致等全部机械项。

## 语感清单（机械查不了的部分）

| # | 检查 | 级别 |
|---|---|---|
| 1 | 中英混排空格：中文与英文/数字之间有空格（「用 git 提交」，非「用git提交」） | error |
| 2 | 全角标点一致：中文语境用全角标点，不用半角逗号句号混排 | error |
| 3 | 表格形态完整：表头分隔行列数与表头一致；行内无断裂的竖线 | error |
| 4 | 链接形态：裸链接后紧跟全角标点时，改用尖括号自动链接 `<URL>`，防渲染器吞标点入链接 | error |
| 5 | 本机信息：提交的内容与提交信息里不出现仓库外的本机信息——项目外路径、主机名、用户名、仓外文件名等 | error |
| 6 | 文档条理：md 按内容选用标题/列表/表格，不堆砌成一个大段落 | warning |

## 处置

- **error**：阻断提交——就地修复后重过门禁，修不动则停下报告（不得静默绕过）
- **warning**：放行，但在回报中列出（连续多次同类 warning = 该立一条规范的信号，向用户提议）

## 代码文件

无独立 lint 工具（零机械资产）时：遵循仓库既有风格；无既有风格则语言社区默认。构建/测试过不了不算过门禁——那是任务自检，不是门禁豁免理由。

## 边界

门禁检查的是**提交内容**，不改变提交纪律本身：一任务一提交、公开面零治理（git-flow.md / SKILL.md）。
